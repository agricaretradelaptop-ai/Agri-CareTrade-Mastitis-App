# Google Play submission checklist

- [ ] Google Play Developer account active
- [ ] App created in Play Console
- [ ] Signed release AAB generated
- [ ] Store listing name and descriptions entered
- [ ] 512 x 512 Play Store icon prepared
- [ ] At least 2 phone screenshots uploaded
- [ ] Feature graphic 1024 x 500 prepared
- [ ] Privacy policy URL published
- [ ] Data safety form completed
- [ ] Content rating questionnaire completed
- [ ] Target audience selected
- [ ] App access declared as no login required
- [ ] Ads declaration set correctly (this build contains no ads)
- [ ] Release uploaded to Internal testing first
- [ ] Test on Samsung/Android phone
- [ ] Promote tested build to Production when ready
